# Chirayu-Thakali.github.io

This is a React site built with Vite. The source entry is `index.html`, shared layout lives in `src/components`, and page-specific content lives in `src/pages`.

## Development

Install dependencies and start the local development server:

```bash
npm install
npm run dev
```

Build the GitHub Pages output into `docs`:

```bash
npm run build
```

The `docs` directory is generated by Vite and should be refreshed with `npm run build` before publishing. Configure GitHub Pages to deploy from the `docs` folder on the selected branch.
