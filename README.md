# Chirayu-Thakali.github.io

This is a React site built with Vite. Shared layout lives in `src/components`, while page-specific content belongs inside `src/App.jsx` or future page components.

## Development

Install dependencies and start the local development server:

```bash
npm install
npm run dev
```

Build the GitHub Pages output into `docs`:

```bash
npm run build
```

The `docs` directory is generated by Vite and should be refreshed with `npm run build` before publishing.
